# Test data

`interlace_buildings.json.gz`: the buildings and building parts of The
Interlace, Singapore (an Overpass API answer, `out geom`, cut to building
elements, coordinates rounded to 7 decimals). Its 87 building parts are
blocks stacked on other blocks, which makes it a good test for ids in 3D.
